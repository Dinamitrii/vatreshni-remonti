# Вътрешни ремонти

Леко Python 3 уеб приложение за фирма за вътрешни ремонти. Включва публичен ценоразпис по категории, администраторски панел и директен WhatsApp бутон. Данните се пазят локално в SQLite (`repairs.sqlite3`), а примерните услуги се добавят автоматично при първо стартиране.

## Стартиране

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export ADMIN_PASSWORD='избери-силна-парола'
export SECRET_KEY='дълъг-случаен-ключ'
python app.py
```

Отвори http://127.0.0.1:5000. Администрацията е на `/admin`; след вход избери „Към сайта“ или отвори `/admin/dashboard`.

В администрацията можеш да смениш името, юридическото име, ЕИК, адреса за картата, района и WhatsApp телефона. Номерът се въвежда в международен формат само с цифри, например `359888123456`. Можеш да добавяш, преименуваш и изтриваш категории, както и да редактираш услугите, описанията и цените. Празна цена се показва като „По договаряне“.

`ADMIN_PASSWORD` и `SECRET_KEY` трябва да бъдат зададени преди публикуване. По подразбиране приложението слуша само на локалната машина; за публичен сървър използвай WSGI сървър и HTTPS.
